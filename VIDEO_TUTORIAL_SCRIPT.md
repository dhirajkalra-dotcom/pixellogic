# PixelLogic Video Tutorial (5–6 min)

## Tutorial Goal
Create a fast, clear product walkthrough that shows a new user how to:
1. Start a new show and configure basics.
2. Build/preview content in **Visualizer**.
3. Send output to **Output Maps** and export images.
4. Generate a project report from **PDF Export**.
5. Briefly introduce advanced tabs: **Projector Test Pattern** and **AI Auto Map**.

---

## Video Specs
- **Length:** 5–6 minutes
- **Format:** 1920×1080, 30 fps
- **Style:** One-take screen capture + clean voiceover
- **Audience:** First-time PixelLogic users

---

## Scene-by-Scene Script

## 0:00–0:20 — Hook + Intro
**On screen**
- Open PixelLogic landing view.
- Keep sidebar tabs visible.

**Voiceover**
> "Welcome to PixelLogic—your all-in-one workspace for LED and projector pattern generation. In this quick tutorial, we’ll go from a blank setup to exported output maps and a PDF report in just a few minutes."

---

## 0:20–1:10 — New Show Setup
**On screen**
- Click **New Shows**.
- Create/select a show.
- Point out **Saved Shows** for revisiting projects.

**Voiceover**
> "Start in New Shows to create a fresh setup. This is where you define your working project. As you continue, your work can be revisited from Saved Shows, so iteration is easy and organized."

**Lower-third text (optional)**
- "Step 1: Create a new show"

---

## 1:10–2:05 — Design + Preview Workflow
**On screen**
- Move to **Visualizer**.
- Demonstrate a map style selection and a quick parameter tweak.
- Use zoom controls and fit-to-screen if visible.

**Voiceover**
> "Next, jump into Visualizer to create and preview your map design. Here you can adjust visual styles and refine the output before committing it. Use zoom and fit controls to inspect details quickly and keep your preview accurate."

---

## 2:05–2:50 — Special Effects (Optional Layer)
**On screen**
- Click **Special Effects**.
- Toggle one effect or modify one setting.
- Return to **Visualizer** to show result continuity.

**Voiceover**
> "Use Special Effects to add creative layers and polish. Even small tweaks here can dramatically change the final look while keeping your core map workflow intact."

---

## 2:50–3:50 — Output Maps + Image Export
**On screen**
- Click **Output Maps**.
- Show map arrangement/output area.
- Export one image format (PNG/JPG) and, if available, show batch save.

**Voiceover**
> "When your design is ready, switch to Output Maps. This is where your final arrangement and deliverables come together. Export as PNG or JPG for immediate use, and use batch export when you need multiple assets quickly."

**Lower-third text (optional)**
- "Step 2: Export output assets"

---

## 3:50–4:35 — PDF Export
**On screen**
- Open **PDF Export**.
- Generate/export report.
- Briefly show saved PDF confirmation.

**Voiceover**
> "For project documentation, open PDF Export. Generate a clean, shareable report with your project details—perfect for approvals, handoff, and production coordination."

---

## 4:35–5:30 — Advanced Tabs Overview
**On screen**
- Briefly click through:
  - **Projector Test Pattern**
  - **AI Auto Map**
- Keep each tab on screen for 5–8 seconds.

**Voiceover**
> "PixelLogic also includes advanced workflows. Projector Test Pattern helps calibration and alignment, and AI Auto Map speeds up setup with intelligent suggestions. You can use these as your project complexity grows."

---

## 5:30–5:50 — Close + CTA
**On screen**
- Return to main view with tabs visible.
- Optional on-screen text: "Create. Preview. Export."

**Voiceover**
> "And that’s the core PixelLogic workflow: create, preview, and export with confidence. If you want, I can also share an advanced tutorial covering projector configuration, test-pattern strategies, and AI-assisted mapping in depth."

---

## Recording Checklist (Quick)
- Close unrelated apps/notifications before capture.
- Set app window to full screen and keep zoom readable.
- Use slow, deliberate cursor movement.
- Pause 1 second before each click.
- Record clean audio in a quiet room.
- Keep one consistent naming convention during demo.
- Export final video as MP4 (H.264), 1080p.
