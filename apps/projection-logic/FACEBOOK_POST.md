🚀 **Pixelogic v1.0.109 is here!** 🎉

The all-in-one desktop toolkit for AV engineers, LED techs, and live-event video pros — built to replace Visio, Excel, and that random calculator app you keep losing. 😅

If you design LED walls, patch processors, or draw signal flows for a living… this one's for you. 👇

---

✨ **What's new in this release:**

🧠 **AV Schematics — fully loaded**
✅ 20 pre-built templates (LED walls, projection mapping, broadcast trucks, NDI, corporate AV, digital signage, worship tech & more)
✅ 50+ AV devices with 14 colour-coded signal types
✅ Real-time signal compatibility checks — catch HDMI-into-SDI mistakes BEFORE you ship 🚨
✅ Network switches (Netgear M4300-24X + generic 8-port) for proper AVoIP routing

🎨 **Canvas Settings Toolbar**
Background presets, dot/line grids, adjustable grid size & brightness, snap-to-grid, minimap toggle — make the workspace yours.

📐 **Rack Elevation View**
Interactive 19″ rack visualization with RU positions, power draw, weight summary — exported as its own PDF page. Hand it straight to the client. 💼

⏪ **Full Undo / Redo** — Ctrl+Z / Ctrl+Shift+Z across every canvas action.

📋 **CSV Device Import** — Bulk-load device lists with fuzzy name matching and automatic port assignment.

🏷️ **Connection Hover Labels** — Hover any cable → see source, destination, port and signal type instantly.

📝 **Document Info Panel** — Project title, author, date, revision, notes — printed on the final PDF page like a proper spec sheet.

📄 **Dark / Light PDF Export** — Match the on-screen look, or go print-friendly white. Your call.

🟪 LED Pixel Map Designer with real-time layout
