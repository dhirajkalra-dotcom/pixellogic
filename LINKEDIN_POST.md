🚀 **PixelLogic v1.0.94 — Major AV Schematics Update**

Excited to share the latest release of **PixelLogic** — a desktop application I've been building for AV professionals, video engineers, and LED technicians.

This update focuses heavily on the **AV Schematics** module, transforming it from a basic signal flow builder into a comprehensive AV system design tool.

---

**What's new in v1.0.94:**

🔧 **20 Pre-Built Templates** — 6 basic + 14 advanced templates covering LED walls, projection mapping, broadcast trucks, NDI streaming, corporate AV, digital signage, worship tech, and more — all organized with category filter tabs.

🎨 **Canvas Settings Toolbar** — Customise your workspace with background colour presets, grid styles (dots/lines), adjustable grid size & brightness, snap-to-grid, and a minimap toggle.

📄 **Dark / Light PDF Export** — Export AV schematics in dark mode (matching the on-screen design) or light mode (white background, optimized for print).

📐 **Rack Elevation View** — Interactive 19″ rack visualization with device slots, RU positions, power draw, and weight summary — also exported as a dedicated PDF page.

⏪ **Undo / Redo** — Full Ctrl+Z / Ctrl+Shift+Z history across all canvas actions.

📋 **CSV Import** — Bulk-load device lists from spreadsheets with fuzzy device name matching and automatic port assignment.

🏷️ **Connection Hover Labels** — Hover any cable to see source → destination device, port, and signal type at a glance.

📝 **Document Info Panel** — Add project title, author, date, revision, and notes — rendered on the final PDF page for professional documentation.

🌐 **Network Switch Devices** — New network category with Netgear M4300-24X and Generic 8-Port switches — Ethernet-based templates now route through dedicated network infrastructure.
