Pixel Map Designer

Define your LED wall dimensions in metres or feet, set panel pixel resolution and physical size, then watch the pixel map update in real time. Build non-rectangular walls — circle, ellipse, triangle, diamond, hexagon, cross or fully custom — size a circle by radius, diameter or circumference, and click-to-paint individual panels. Multiple maps per project, panel presets, gradient or checker fill, and one-click PNG export.

Pixel Map Designer with shape-based walls

Set your LED wall physical dimensions in metres, define the panel pixel resolution (e.g. 128×128 px at 500×500 mm) and watch the pixel map update in real time. Build non-rectangular walls — circle, ellipse/oval, triangle, diamond, hexagon, cross/plus or fully custom — while the project still calculates as a grid so export, 3D, patching and power all keep working.

  • ✓ Shape walls — circle, ellipse, triangle, diamond, hexagon, cross or custom
  • ✓ Size a circle by radius, diameter or circumference
  • ✓ Click-to-paint panels for logos, letters & irregular walls
  • ✓ 65+ LED tile presets — gradient or checker fill

Special effects & overlay system

Superimpose visual overlays directly onto your pixel maps for testing and documentation. Add numbered centre badges, pixel coordinate readouts, custom logo watermarks, centre target circles and per-corner alignment markers — each independently configurable.

  • ✓ Numbered centre badges for multi-screen ID
  • ✓ Pixel coordinate grid overlay
  • ✓ Custom logo watermark import
  • ✓ Centre & corner alignment circles

2D full-resolution visualizer

Preview your LED wall as a flat, full-resolution 2D representation. Combine multiple pixel maps into a single composite view with alignment handles, zoom controls and pixel-accurate readouts. Ideal for checking content alignment before going on-site.

  • ✓ Full-resolution flat preview
  • ✓ Combine multiple pixel maps
  • ✓ Zoom & pan with pixel readouts
  • ✓ Content alignment verification

Interactive 3D LED wall visualizer

Preview your LED wall in an interactive 3D perspective view with UV texture overlay, grid display and axis indicators. Rotate, zoom and orbit freely using camera presets (Front, Top, Side, Isometric) for client presentations and pre-visualisation.

  • ✓ Interactive 3D perspective with orbit controls
  • ✓ UV texture overlay & grid display
  • ✓ Camera presets — Front, Top, Side, Isometric
  • ✓ Status bar with resolution & panel info

4K UHD output canvas with draw mode

Place your pixel maps on a 4K UHD canvas (3840×2160 default) with pixel-accurate grid, rulers and snapping. Switch on Draw Mode to sketch workflow lines and arrows for LED installers — multicolour, adjustable line widths with straight-line or freehand modes.

  • ✓ 4K UHD canvas — custom resolution support
  • ✓ Grid, rulers and snapping for precision placement
  • ✓ Draw Mode for installer workflow annotation
  • ✓ Save PNG / JPG / Transparent PNG

LED processor patching & data routing

Select from 22+ LED processors, define your display array and output card. The app calculates port allocation automatically, assigns data cable snake patterns and configures power patching per zone — including circuit breaker sizing.

  • ✓ 22+ LED processors supported
  • ✓ Data snake pattern — auto port allocation
  • ✓ Power patching & circuit breaker calculator
  • ✓ Export DATA & POWER views as PNG or PDF

AV schematics with 50+ device catalog

Build professional signal-flow diagrams using a built-in catalog of 50+ AV devices covering media servers, LED processors, switchers, audio consoles and more. Supports 14 signal types with colour-coded connections, 20 schematic templates, and both schematic and rack-elevation views.

  • ✓ 50+ devices — media servers, switchers, LED processors & more
  • ✓ 14 signal types with colour-coded wiring
  • ✓ Schematic view + Rack view
  • ✓ PNG / PDF / CSV export

Professional PDF & PPTX export

Generate branded, presentation-ready documentation with one click. The PDF Export Control Room lets you preview each page, customise headers and project metadata, then export pixel maps, LED patches, power reports and AV schematics as multi-page PDF or PowerPoint PPTX.

  • ✓ Multi-page PDF with cover & sections
  • ✓ PPTX for client presentations
  • ✓ Technical rider & cable schedule CSV
  • ✓ Branded headers & project metadata

LED power calculator

Calculate complete power requirements for your LED installation. Select from 65+ LED tile models from leading manufacturers, enter your panel count, and the app generates a full power report with per-panel wattage, total amperage, 3-phase distribution and circuit breaker recommendations.

  • ✓ 65+ LED tile models from leading manufacturers
  • ✓ Per-panel wattage & total amperage
  • ✓ 3-phase power distribution calculator
  • ✓ Circuit breaker sizing recommendations

Misc tools & utilities

Access handy utility tools built into Pixelogic. The Aspect Ratio Calculator helps you determine optimal resolution and scaling for any display format. The SMPTE LTC WAV Generator creates timecode audio files for synchronised playback across media servers.

  • ✓ Aspect Ratio Calculator
  • ✓ SMPTE LTC WAV Generator
  • ✓ Resolution & scaling reference
  • ✓ Timecode sync for media servers
