What's Inside

Built for the
show-caller's table

StageCue gives operators surgical control over the timer the speaker sees — on a laptop, a phone, an X-keys panel, a Stream Deck, OBS or even a custom webhook.

Big Fullscreen Display

Auto-detects external monitors (hot-plug supported). Pick which display the speaker sees and StageCue opens a borderless, fullscreen countdown there — large digits, optional clock, end-time and progress bar.

Auto DetectHot-plugPer-display

Warning, Critical & Overtime

Configurable yellow warning and red critical thresholds (in seconds). Past zero, the timer flips to overtime mode and counts up with flashing red — so a polite speaker gets the message.

Yellow / RedFlash ModesCount-up

Speaker Messages

Show typed messages above the timer with one click: "5 min left", "wrap up", "time is up" or your own. Optional flashing. Auto-messages can fire at warning, critical and end thresholds.

Quick PresetsCustom TextAuto-fire

Full-Screen Layers NEW

Slam an urgent full-screen cue over the countdown — STOP, WRAP UP, STAND BY or custom text, in a neutral or hot-red tone. One key (1 / 2 / 3) shows it, 0 hides it. Layers appear on the speaker display and the OBS source, independent of the normal message line.

STOP / Wrap UpNeutral / HotHotkeys

Instant Display Blackout NEW

One Blackout button (or the B key) instantly cuts the speaker display to black — perfect for scene changes, walk-ons or holding the room — while the timer keeps running in the background. Tap again to restore. Mirrored to the OBS source and exposed to Companion / the API.

1-tap / B keyTimer Keeps RunningCompanion + API

Multi-Speaker Sessions

Build a running order with names, durations and notes. Jump between speakers with one click, see the next speaker on stage, and keep timings consistent across multi-talk sessions.

Running OrderNext-upNotes

Phone Remote (QR)

Start the built-in phone remote and scan the QR. Any phone on the same network gets a clean web UI to start, pause, send messages, ±time, jump speakers — protected with an auto-generated API key.

QR PairingAPI KeyWeb UI

OBS Browser Source

A transparent browser-source URL drops the timer straight into your OBS scene for live streams — same colours, same warning logic, no chroma key needed.

TransparentOBS-ready1 URL

REST + WebSocket API

Drive StageCue from anything: a webhook, a show-control system, a Python script. Full REST endpoints for start/pause/stop/adjust/cue plus a WebSocket feed of live timer state.

RESTWebSocketAPI Key

Bitfocus Companion Module

A native Companion module ships with the installer — one-click button presets for Start / Pause / Stop, ±seconds, jump speaker, send cue, plus live $(stagecue:remaining) variables and feedback colours.

Stream DeckX-keysLive feedback

Sound Alarms

Built-in audible alarms at warning, critical and end-of-time. Multiple alarm styles to match the room. Silence on demand from controller, phone or Companion button.

Multi-stylePer-thresholdOne-tap silence

Branded Display

Customise the speaker-facing display: title, sponsor logo, optional wall clock, end-time and progress bar — all toggleable per show.

LogoWall ClockEnds-at

Keyboard Shortcuts

Space start / pause, R reset, C clear message, Esc closes the speaker display. Fast, ergonomic, made for an FOH operator.

SpaceRC / Esc

100% Offline

No cloud, no accounts, no internet required after install. The remote, OBS source and API run on your local network only — safe on closed event LANs.

No CloudLocal LANAPI Key

OSC over UDP & TCP NEW

Broadcast every timer event over Open Sound Control — UDP or TCP for reliable show-control runs. Perfect for QLab, ETC Eos, MA3, Resolume, TouchDesigner, Isadora and any OSC-aware system.

UDP / TCPQLabEos / MA3

Art-Net & sACN Lighting NEW

Drive DMX values from timer state — turn the room red on overtime, fade strobes at the warning threshold, or pulse a cue light when the speaker should wrap. Native Art-Net and sACN (E1.31) output.

Art-NetsACN E1.31DMX Cues

MIDI Show Control NEW

Send MSC GO, STOP, RESUME messages on timer events to lighting consoles, sound playback systems and theatre automation — the same protocol used by every major show-control desk for decades.

MSCGo / StopUniversal

Outgoing Webhooks NEW

Fire HTTP POST requests on every significant event — start, pause, warning, critical, overtime, speaker change. Hook into Slack, Microsoft Teams, Zapier, n8n or your own dashboards.

HTTP POSTJSON PayloadPer-event

OBS WebSocket Control NEW

Beyond the browser source — StageCue can now drive OBS directly via OBS WebSocket. Switch scenes on speaker change, start recording when the timer starts, mute mics on overtime. All from one operator surface.

OBS WS v5Scene SwitchingDirect Control

Companion Setup Wizard NEW

A guided one-click wizard inside the app installs the Bitfocus Companion module, starts the StageCue server, and tests the connection — no manual file copying, no config files. From install to live Stream Deck in under a minute.

GuidedOne-clickSelf-test

How It Works

From speaker brief to
live show in 4 steps

01

Plug In

Connect the second monitor (HDMI / SDI converter / NDI). StageCue auto-detects it and offers it as the speaker display.

02

Set Times

Pick duration, warning and critical thresholds, choose alarm style, and brand the display with a title or logo.

03

Run the Show

Start with Space, send a message with one click, jump speakers, ±time on the fly — from controller, phone or Stream Deck.

04

Stay In Control

Past zero, overtime mode flashes red. Your speaker sees the cue, the alarm fires, and the show stays on schedule.
