# PixelLogic Advanced Deep Dive (8–10 min)

## Focus
This tutorial covers two advanced workflows only:
1. Projector Test Pattern for calibration and validation
2. AI Auto Map for faster mapping setup and iteration

---

## Video Specs
- Length: 8–10 minutes
- Format: 1920×1080, 30 fps
- Delivery style: Screen capture + guided voiceover
- Audience: Users already familiar with basic PixelLogic workflow

---

## Learning Outcomes
By the end of this video, viewers will be able to:
- Configure projector grid settings and preview behavior
- Validate pattern readability and layout consistency
- Export test pattern outputs for deployment and review
- Use AI Auto Map as a starting point, then refine manually
- Decide when to use manual setup vs AI-assisted setup

---

## Scene Plan + Narration

## 0:00–0:35 — Intro: What this advanced tutorial covers
**On screen**
- Open PixelLogic with sidebar visible
- Brief hover over Projector Test Pattern and AI Auto Map tabs

**Voiceover**
"In this advanced PixelLogic tutorial, we’ll focus on two high-impact features: Projector Test Pattern for alignment and validation, and AI Auto Map for faster mapping setup. This video is for users who already know the core create-preview-export workflow and want speed plus precision."

---

## 0:35–1:20 — When to use each feature
**On screen**
- Click Projector Test Pattern, then AI Auto Map, then back

**Voiceover**
"Use Projector Test Pattern when you need confidence in geometry, overlap, labeling, and output consistency before production. Use AI Auto Map when you want a fast initial mapping proposal that you can fine-tune manually. Together, they reduce setup time and improve reliability."

---

## 1:20–3:40 — Projector Test Pattern: Core setup
**On screen**
- Open Projector Test Pattern
- Show key fields: projector width and height, projectors horizontal and vertical
- Toggle auto-calc option if visible
- Demonstrate changing one setting at a time and observing preview updates

**Voiceover**
"Start by entering projector resolution and grid layout values. Set horizontal and vertical projector counts to reflect your real deployment. If auto-calc is available, use it for a practical baseline, then fine-tune manually for edge cases. Make one change at a time and validate each preview update before moving forward."

**On-screen tip**
- Tip: Change one variable at a time for cleaner troubleshooting.

---

## 3:40–5:20 — Visual validation and naming discipline
**On screen**
- Show main preview canvas
- Edit projector names and colors
- Demonstrate readability of labels and index consistency
- If dome/circular option exists, toggle it briefly and show second preview

**Voiceover**
"Now validate readability and structure. Assign projector names clearly and keep numbering consistent with your physical rig. Color coding helps spot mistakes quickly, especially in larger arrays. If you use circular or dome-like layouts, verify both standard and circular views so operators can map quickly in the field."

---

## 5:20–6:20 — Export outputs from Projector Test Pattern
**On screen**
- Use Save PNG and Save All PNGs if available
- Generate Projector Test Pattern PDF if available
- Briefly show success state or output files

**Voiceover**
"Once validation is complete, export your outputs. Use single PNG export for spot checks, batch PNG export for full handoff packages, and PDF output for formal documentation and approvals. Keep naming conventions stable so your operations and playback teams can consume files instantly."

---

## 6:20–8:10 — AI Auto Map: Fast baseline generation
**On screen**
- Switch to AI Auto Map
- Enter or select available inputs
- Trigger AI mapping action
- Review generated output and transition to preview tabs

**Voiceover**
"Next, use AI Auto Map to accelerate setup. Provide the cleanest possible inputs and let PixelLogic generate an initial map structure. Think of this as your first draft: fast, useful, and ready for refinement. After generation, review results in your normal preview flow and adjust for artistic or technical constraints."

**On-screen tip**
- Tip: AI gives a strong starting point; final quality comes from targeted manual refinement.

---

## 8:10–9:10 — Refinement loop: AI + manual adjustments
**On screen**
- Move between AI Auto Map result and preview/adjustment controls
- Apply one or two small manual edits
- Re-check output consistency

**Voiceover**
"The best production workflow is hybrid: generate quickly with AI, then refine manually where needed. Prioritize alignment accuracy, naming consistency, and export readiness. This loop gives you speed without sacrificing control."

---

## 9:10–9:50 — Decision framework and close
**On screen**
- Show both tabs side-by-side in quick cuts
- Return to main view

**Voiceover**
"Use Projector Test Pattern when calibration and operator clarity are the priority. Use AI Auto Map when speed is the priority. In real projects, combine both: AI for baseline, test patterns for validation, then export with confidence."

## Quick Presenter Notes (for smooth delivery)
- Keep cursor movement slow and intentional
- Pause half a second before each click
- Avoid changing more than one parameter per step
- Narrate reason before action: why this change matters
- Keep terminology consistent: projector grid, overlap, preview, export

## Recording Checklist (Advanced)
- Prepare one realistic demo scenario in advance
- Decide naming scheme before recording (example: P1, P2, P3…)
- Pre-test one successful AI Auto Map run to avoid dead air
- Keep export folder open for quick result reveal
- Use the same output naming pattern throughout the demo
- Record room-tone for 5 seconds before narration (helps audio cleanup)
